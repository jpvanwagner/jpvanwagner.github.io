# Portfolio

My professional portfolio, gamified: a retro 90s desktop with a "Traditional View" for regular browsing.
Live site: https://jvanwagner.neocities.org/

## Deploy
Upload everything in this repository (except `README.md` and `DEVELOPER-NOTES.md` if you like) to the root of
the Neocities site. No build step.

- Free Neocities accounts do not accept audio/video: skip the `.mp3`/`.mp4`/`.docx` files under `work/`
  (the sample courses still work, just without narration).

See `DEVELOPER-NOTES.md` for a map of the code.
