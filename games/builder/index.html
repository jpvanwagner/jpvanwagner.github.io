QUIZCADE BUILDER

Pick a game, change the questions, words, colors and pictures, then copy the finished HTML into Rise 360, a website, or anywhere else that takes HTML.

1. PICK A GAME

Start from one of the games, or open a game file you made before (any Quizcade .html file, including ones exported from here).

2. QUESTIONS

Each question needs 2 to 4 answers. Pick the correct one in the last column. Empty answer boxes are left out.

Paste questions from a spreadsheet (Excel, Google Sheets, CSV)…

Copy rows with these columns and paste below: Question | Answer A | Answer B | Answer C | Answer D | Correct. "Correct" can be the letter (A–D), the number (1–4) or the answer's exact text. Leave unused answer cells blank. A header row is skipped automatically.

5. COLORS

Click a swatch to pick a color, or type any CSS color (#ff0000, red, rgba(255,0,0,0.5)).

6. SPRITES & BACKGROUNDS

Upload a picture (PNG with a see-through background works best) to replace a sprite, or edit its pixel art. Big pictures are shrunk automatically so the game stays small. Draw players facing right.

7. MAZES

Level 1 uses the first maze, level 2 the second, and so on, starting over after the last.
# wall   . dot   space empty   - ghost door   P player start   G ghost start (one ghost each). Rows open at both ends wrap around. The tutorial uses the first maze's first long straight corridor (19+ squares).

PREVIEW

GET THE HTML

The complete game in one HTML file. Use it for Rise 360 → Code block (paste it all in), save it as a .html file to upload to a website (e.g. Neocities), or open it straight from your computer.

A self-contained <iframe> you can paste into any page's HTML (Squarespace/WordPress/Google Sites "embed" or "custom HTML" blocks, blogs, LMS pages). The game runs in its own box, so it can't clash with the page, and you can put several games on one page.

Uploaded the .html file somewhere (Neocities, GitHub Pages, your LMS)? Paste its web address to get embed code that loads it from there. This also works with Rise 360 → Embed blocks (they take the address or the code).
