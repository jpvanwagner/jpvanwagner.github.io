Quizcade

Three arcade quiz games, plus a builder to make them your own.

Quizcade is my set of arcade-style quiz games, built to turn training review into something people actually want to replay. Each one asks quick multiple-choice questions between bursts of play, and each is a single self-contained web page, so it drops straight into a Rise 360 Code block, an LMS, or any website. In training, they reviewed software skills; the versions here use easy general trivia so anyone can jump in.

The Quizcade Builder

The Builder edits everything about each game without touching any code, with a live preview as you go:

  • Questions: type them in, or paste rows straight from Excel or Google Sheets; each can have 2 to 4 answer choices.
  • Words: every title, button, tutorial step, and hint, so a game can be retitled or translated.
  • Rules and colors: lives, questions per level, points, speeds, and every color, including the A/B/C/D answer colors.
  • Pictures: swap in your own sprites and backgrounds, or edit the pixel art, and rework Quiz-Guy's mazes.
  • Export: copy the finished game as a whole web page, an embed code, or a hosted link, ready for Rise 360, an LMS, or a website.
