README
======

Thanks for visiting my portfolio. This site is built like a
1990s computer, but everything here is real: my background,
sample courses, and learning games I built.

GETTING AROUND
--------------
* Double-click a desktop icon to open it (on a phone or tablet,
  tap once).
* Or click MENU in the bottom-left corner for every page,
  program and setting.
* Pages open in the NetCrawler browser. Use the + button above
  the page to open more tabs.
* Right-click the desktop, icons, window title bars, taskbricks
  and the drawer tabs for more options.

CLASSIC VIEW
------------
Prefer a regular website? Click MENU > "Switch to Classic
View", or double-click the "Traditional View" icon. The "Retro
Desktop" button at the top of any page switches back.

YOUR OWN FILES
--------------
Right-click the desktop to make a new folder or text document.
They're saved only in this browser. Drag things onto the Rubbish
bin to throw them away; open the bin to get them back.

SEARCH
------
Click the magnifier at the top of any page, choose MENU > Find,
or just type words into NetCrawler's address bar.

GAMES
-----
Open the Games folder (desktop or MENU > Games) to play the
quiz games I programmed for software training. Click inside a
game first so it can hear your keyboard.

SETTINGS
--------
MENU > Settings > All Settings... lets you:
* turn off the boot animation or the tips for new visitors
* set the screen saver delay
* switch browser tabs on or off, and change the text size
Your choices are saved in this browser only.

CUSTOMIZING
-----------
* TOOLS (right edge): colors, themes, wallpapers, fonts, and a
  CRT scanline effect.
* DOODLETOP (right edge): draw on the screen. Right-click or
  press Esc to stop drawing.
* Right-click either tab to hide it, or to let windows cover it.
* The corner button next to the clock switches full screen on
  and off (Esc also exits). The speaker next to it sets this
  site's volume.
* Like what you see? MENU > Share this site... or
  MENU > Add to Favorites...
