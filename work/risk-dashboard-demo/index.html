🫧 Ripple Map: Reference

What This Tool Is

Ripple Map is a mockup of a live cross-department issue heatmap, a visualization tool meant to demonstrate how operational health in one part of a contract security organization creates pressure (or relief) in others. It is a presentation and training aid, not a production system. The simulations below illustrate real organizational dynamics and are loosely modeled on documented incidents in the contract security industry.

Glossary

IssuesThe number of open or active problems in a department. Higher issues push that department's dot outward, toward red. Set to 0 for "clean."
AgeHow long issues have persisted (1–10). Age 1 is fresh/green; age 10 is chronic/red. Older issues represent compounding organizational risk.
RippleHow strongly a department's issues radiate outward to its immediate neighbors on the chart. High ripple = compounding adjacent pressure.
Base %The department's raw share of total issues across the organization, before ripple effects.
Affected %The dept's chart position after all neighbors' ripple is applied. This is what the dot actually shows.
IntensityPer-simulation severity slider (1–5). 1 is barely-there; 5 simulates a serious organizational crisis.

Particles, Resolutions & Log

Particles are now event-driven. They fire only when something actually happens: a ripple particle travels from a department whose issues just rose to its neighbors, and a gold "cascade" particle fires when a simulation phase activates a new downstream department. When issues drop, the resolved dot briefly flashes green and shrinks, then returns to its age color.

The Log subwindow (lower-right) records every event with a scenario-specific message, issue spike, resolution, cascade, alive drift, district filter changes, etc. Toggle the eye icon (👁/⌃) on each subwindow to collapse or hide it.

Cures & Recovery

Each scenario has a corresponding cure, a multi-phase intervention that realistically reallocates resources to bring the situation back to green. The 💊 pill button next to each scenario card activates its cure (only available while the scenario is running).

Cures don't add issues; they override the scenario's targets, ramping each affected department's issues down to zero across several phases. Each phase logs the specific intervention happening (e.g., "Talent Acquisition surge activated", "FLSA settlement framework agreed", "Mutual aid from neighboring districts"). When the cure reaches its final phase, it auto-stops both itself and the parent scenario, with a recovery-complete message in the log.

Territory Map

The Map subwindow (lower-left) is an interactive sample territory map. Switch between Country, District, and State selection modes. When a district or state is selected, the active simulations are scoped to that geography, intensities are dampened to reflect partial coverage, and the log notes the filter context. Clear the selection to return to nationwide simulation.

The Chart

  • Concentric rings run green (inner, safe) to red (outer, critical). A dot's distance from center tells you how severe that department is.
  • Age-colored dots color each dot by the age of its issues, green (new) through yellow to red (chronic).
  • Gradient amoeba fill colors the polygon using each department's age color, creating a soft visual gradient between vertices.
  • Dept Analyses are floating info boxes near each dot. "On Hover" is best for clean demos; "Always" shows them all permanently.
  • Dot Labels show count and age directly next to each dot in count·age format.
  • Particle flow lines visualize ripple as small particles traveling between dots, origin pulse, traveling segment (routed around obstacle dots), and a destination ping where they land.

Simulations

Each simulation models a realistic organizational scenario. Use the Intensity slider (1–5) on each card to control severity, and the global Speed slider to control cascade speed. Toggle Multi to run several simulations together. The Freeze button pauses everything in place; Stop clears all simulations.
