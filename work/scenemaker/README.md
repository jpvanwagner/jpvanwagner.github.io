# Scenemaker (portfolio demo)

A browser-only demo of **Scenemaker**, a node-graph branching-scenario and visual-novel authoring
tool that exports SCORM 1.2 packages, single-file HTML stories and printable storyboards.

- Try it: open `index.html` (overview) or `app/editor/editor.html` (the editor).
- Sample output: `downloads/whistleblower-sample.html` plays in any browser.

This demo runs entirely in the browser: saving downloads a project file, SCORM/EXE export is
disabled, and exports made here carry a small credit line.
