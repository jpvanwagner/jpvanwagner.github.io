Keys for outside services Scenemaker talks to; its own separate section since these aren't editor preferences, and this project's Story/Screen/etc. settings never touch a network. External asset sources

API keys for the online asset browser (Assets panel → 🌐 browse online). Pixabay/Pexels/Unsplash (images, video), Freesound/Jamendo (audio) and Smithsonian (images) each need your own free key below, since Scenemaker can’t ship one shared key without breaking that source’s terms. Wikimedia Commons, NASA Images, the Met Museum and Openverse need no key at all and aren’t listed here; they’re just always available in the browser. Freesound and Jamendo’s free tiers are non-commercial use only, and Openverse’s license varies per result (it aggregates from many sources) - both are flagged in the browser itself.
